# Rock_vs_Mine_Prediction
🛰️ Rock vs Mine Prediction — A binary classification project using Logistic Regression to classify sonar signals as Rock or Mine. Built with Python, Pandas, NumPy, and Scikit-learn, covering EDA, stratified train/test splitting, model training, evaluation, and single-sample prediction. Achieves 83.42% training accuracy and 76.19% test accuracy.
